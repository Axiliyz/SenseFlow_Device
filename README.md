# SenseFlowDevice

Прошивка для Arduino-устройства, снимающего PPG-сигнал (фотоплетизмограмму) по двум каналам одновременно и дополнительно измеряющего сопротивление кожи. Данные пишутся на SD-карту с таймстампами от RTC, управление — с клавиатуры 4×4, показания ЧСС выводятся на LCD в реальном времени.

Парная часть системы — [SenseFlowApp](https://github.com/Axiliyz/SenseFlowApp), приложение для просмотра и анализа записанных сессий.

## Возможности

- Одновременный сбор сигнала с двух аналоговых каналов с частотой дискретизации 120 Гц через прерывания Timer1
- Детекция пиков пульса по адаптивному порогу с медианной + экспоненциальной (EMA) фильтрацией сырого сигнала
- Расчёт ЧСС (BPM) по интервалам между пиками с отсечкой физиологически невозможных значений (40–180 BPM)
- Измерение сопротивления через ADS1115 с полиномиальной коррекцией нелинейности датчика
- Двойная буферизация записи на SD-карту (запись в фоне не блокирует сэмплирование)
- Управление стартом/стопом записи с клавиатуры, отображение ЧСС и таймера на LCD

## Железо

| Компонент | Назначение | Пины |
|---|---|---|
| Аналоговые каналы PPG | Съём сигнала пульса, 2 канала | A6, A2 |
| ADS1115 | АЦП для измерения сопротивления | I2C |
| DS1302 (RTC) | Таймстампы для файлов на SD | RST=8, DAT=7, CLK=6 |
| SD-карта (SPI) | Хранение записанных сессий | CS=10 |
| LCD 16x2 (I2C) | Индикация ЧСС и таймера | I2C, адрес 0x27 |
| Клавиатура 4x4 | Старт (`1`) / стоп (`2`) записи | строки 9,8,7,6 / столбцы 5,4,3,2 |

## Формат записи

При старте записи создаются два файла на SD-карте с именем на основе текущей даты/времени (`ДДММГГ_ЧЧММСС.txt`):

- Основной файл — строки `bpm1 bpm2 R` (ЧСС по каждому каналу + сопротивление)
- Файл с префиксом `D` — отфильтрованные сырые значения обоих каналов, для последующего анализа формы сигнала

## Зависимости (Arduino-библиотеки)

`Wire`, `LiquidCrystal_I2C`, `SdFat`, `RtcDS1302`, `ThreeWire`, `Adafruit_ADS1X15`, `Keypad`
